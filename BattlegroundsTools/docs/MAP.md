# Repo map

One line per module: its docstring summary and public names. Read this instead of opening
files. Private names (leading `_`) and tests are left out.

GENERATED by `python build_and_test/tools/make_map.py`. Do not edit by hand; a test checks
that it is current.

Layers (imports point inward only): `core` <- `analysis`, `file_adapters`, `ui` <- `modes`
<- `commands` <- `__main__.py`, `menu.py`.

- `bgtools/__main__.py` - Entry point: python -m bgtools  (and the one the .exe is built from).
  - cmd_track(args) -> None
  - cmd_minions(args) -> None
  - cmd_targets(_args=None) -> None
  - cmd_demo(args) -> None
  - cmd_menu(_args=None) -> None
  - build_parser() -> argparse.ArgumentParser
  - main(argv: Optional[List[str]]=None) -> int
- `bgtools/analysis/board_type.py` - Works out what kind of board you have.
  - build_label(counts: Counter, wild: int, size: int) -> Tuple[Optional[str], str]
  - build_profile(races_per_minion: Sequence[Sequence[str]], size: int) -> Profile
- `bgtools/analysis/minion_search.py` - Filtering the minion list by tier, type and search text.
  - filter_minions(...) -> List[Minion]
- `bgtools/analysis/recommender/__init__.py` - Advice rules. Each rule reads the board Profile and returns plain data.
  - discover()
- `bgtools/analysis/recommender/rules.py` - Rules that mark tavern minions worth a look.
  - rule(fn: Rule) -> Rule
  - triple_target(m: Minion, main: Optional[str], targets: TargetMap) -> Optional[Mark]
  - fits_board(m: Minion, main: Optional[str], targets: TargetMap) -> Optional[Mark]
  - pick_marks(...) -> Dict[int, Mark]
- `bgtools/analysis/stats.py` - Numbers about boards and finished games.
  - board_strength(minions: Iterable[Minion]) -> Strength
  - compare_to_history(record: GameRecord, history: List[Mapping]) -> Comparison
- `bgtools/commands/__init__.py` - Commands: what `python -m bgtools <name>` can do. Connects modes to adapters.
  - discover()
- `bgtools/commands/registry.py` - The command registry. A command is a function marked with @command.
  - command(...)
- `bgtools/core/discovery.py` - Import every module in a package whose name starts with a prefix.
  - import_matching(package: str, prefix: str) -> List[str]
- `bgtools/core/domain.py` - Plain data types and tiny pure helpers shared by every layer.
  - to_int(value) -> Optional[int]
  - normalize_races(raw: Sequence[str]) -> List[str]
  - clean_text(text: Optional[str]) -> str
  - class Card
  - class Minion
  - class Profile
  - class Strength: total
  - class Mark
  - class Status
  - class GameRecord: to_dict
  - class Comparison
  - class MatchPanel
  - class Snapshot
- `bgtools/core/game_state.py` - Rebuilds a game from Hearthstone's Power.log, one line at a time.
  - describe(entity: dict, by_id: Dict[str, Card]) -> Minion
  - class State: reset, ent, learn, feed, sample_board, placement, finish, controller_of, game_tags, player_tags, minions, minion_views, status
- `bgtools/core/paths.py` - Where bgtools keeps its files.
  - app_root() -> Path
  - data_dir() -> Path
  - targets_file() -> Path
  - history_file() -> Path
  - cards_cache_file() -> Path
  - readme_file() -> Path
- `bgtools/core/ports.py` - Contracts the inner layers need. The adapters in file_adapters/ fulfil them.
  - class CardSource: by_id, minions, tier_by_name, refresh
  - class LogSource: lines, switch_if_newer
  - class HistoryStore: load, save
  - class TargetsStore: load, read_entries, write_entries
- `bgtools/file_adapters/cards_hsjson.py` - Card data from HearthstoneJSON (https://hearthstonejson.com), cached on disk.
  - parse_cards(raw: List[dict]) -> List[Card]
  - is_bg_minion(card: Card) -> bool
  - class HearthstoneJsonCards: refresh, by_id, minions, tier_by_name
- `bgtools/file_adapters/log_replay.py` - Reads a finished Power.log from the top, once. Used for tests and for --replay.
  - class ReplayLog: lines, switch_if_newer
- `bgtools/file_adapters/log_tail.py` - Reads Hearthstone's Power.log while the game is still writing it.
  - default_logs_dir() -> str
  - newest_log(logs_dir: str) -> Optional[str]
  - class LogTail: lines, switch_if_newer, close
- `bgtools/file_adapters/stores_json.py` - Your finished games, saved as history.json.
  - class JsonHistoryStore: load, save
- `bgtools/file_adapters/targets_txt.py` - triple_targets.txt: one 'Card name | short reason' per line.
  - class TextTargetsStore: load, read_entries, write_entries
- `bgtools/menu.py` - The numbered menu. It only shows choices and calls the functions it is given.
  - run_menu(actions: Dict[str, Action], extra: Sequence[Tuple[str, str, str]]=()) -> None
- `bgtools/modes/game_review.py` - Finished games: save them once, and compare each with your earlier ones.
  - record_finished(state: State, history: List[dict], store: HistoryStore) -> None
  - build_match_panel(state: State, history: List[dict]) -> Optional[MatchPanel]
- `bgtools/modes/live_tracker.py` - The live tracker: follow Power.log while you play and redraw the screen.
  - build_snapshot(...) -> Snapshot
  - run(...) -> None
- `bgtools/modes/minion_browser.py` - Browse every Battlegrounds minion, grouped by tavern tier.
  - print_minions(minions: Sequence[Minion], use_color: bool) -> None
  - query_parser() -> argparse.ArgumentParser
  - interactive(minions: Sequence[Minion], use_color: bool) -> None
  - run(...) -> None
- `bgtools/modes/triple_targets.py` - Pick your favorite minions for triple_targets.txt.
  - show_list(entries: List[Tuple[str, str]], tiers: Dict[str, int]) -> None
  - run(minions: Sequence[Minion], store: TargetsStore) -> None
- `bgtools/ui/bgui.py` - bgui.py - low-level terminal styling (colors, banner, header, badges, wrapping).
  - set_enabled(on)
  - c(text, *codes)
  - term_width()
  - banner(text, color="1;93")
  - header(title, count=None, color="1;93", note="")
  - tier_badge(tier)
  - highlight(line)
  - minion_lines(...)
  - tracker_banner()
  - frame(text)
- `bgtools/ui/components/debug_footer.py` - The --debug footer: raw values behind the screen.
  - debug_footer(snap: Snapshot) -> List[str]
- `bgtools/ui/components/match_panel.py` - The MATCH COMPLETE panel shown after a game ends.
  - match_panel(snap: Snapshot) -> List[str]
- `bgtools/ui/components/minion_list.py` - A titled list of minions: the tavern, your board, your hand.
  - section(...) -> List[str]
- `bgtools/ui/components/status.py` - The three summary lines under the title: status, board type, triple targets.
  - status_line(snap: Snapshot) -> List[str]
  - board_line(snap: Snapshot) -> List[str]
  - triple_line(snap: Snapshot) -> List[str]
- `bgtools/ui/layout.py` - Chooses the fullest tracker layout that fits the window, so the screen never scrolls.
  - render_screen(snap: Snapshot, show_text: bool=False, rows: int=40) -> str
- `bgtools/ui/sandbox/demo.py` - Draws UI pieces from made-up data so you can build one without playing a game.
  - fake_snapshot() -> Snapshot
  - run(name: Optional[str]=None, rows: int=40) -> int
